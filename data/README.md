# Local project data (not committed)

The original client and property CSV files are intentionally excluded from this
public GitHub-ready package because client records may contain personal or
identifying information (for example, names and dates of birth).

To run the project locally, place authorised copies of the following files here:

- `data/clients.csv`
- `data/properties.csv`

Then run the preprocessing and analysis scripts from the project root. The
processed files are generated under `data/processed/`.

Do not upload real client-level data, direct identifiers, or transaction-level
records to a public repository. If you have explicit permission to publish data,
review and anonymise it first.
